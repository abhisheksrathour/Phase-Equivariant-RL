# Phase-Equivariant-RL32-GBaud DP Gray 16-QAM; 2048 symbols/polarization; two samples/symbol; root-raised-cosine roll-off 0.1; periodic FFT blocks; eight 80-km spans; fiber loss 0.2 dB/km, dispersion −21.7 ps²/km, Kerr coefficient 1.3 W⁻¹km⁻¹; EDFA noise figure 5 dB; wavelength 1550 nm. Launch power is aggregate over both polarizations and normalized in expectation, retaining finite-block symbol-energy fluctuations. The primary forward solver uses 16 steps/span. The amplifier noise model uses the explicitly stated high-gain approximation in Equation (6).
The primary receiver excludes 128 symbols at each edge and known pilots every 16 retained symbols. It evaluates 1680 payload symbols/polarization and 13,440 bits/frame. Each case/power/method has 24 frames and 322,560 bits. SNR is EVM-derived, not optical SNR. All methods share pilots and ASE. Pilot recovery uses only known pilots. The network has no true phase or payload-symbol input at inference. Common phase is different from time-varying Wiener phase.
`primary_results.csv` has 7560 method-frame rows. `retraining_results.csv` has 9720 single-head rows; the name refers to the three retained initializations, not repeated tuning after final testing. Bootstrap intervals are paired over 24 seed blocks, 4000 resamples, conditional on fitted estimators. They are pointwise and do not establish broad superiority. Zero observed errors are never treated as proof of zero BER.
